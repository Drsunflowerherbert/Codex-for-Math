# Official solution access — opt in

These registries link answers and sometimes combined papers containing both
questions and solutions. Opening a registry can expose spoilers. Our original
proofs are kept in a separate [authored-solution index](solutions/README.md).

- [Yau solution availability](catalogs/yau-official-solutions.md): specific archived
  Analysis answer members and bounded not-located statuses.
- [Schweitzer solution availability](catalogs/schweitzer-solutions.md): official,
  preliminary official, organizer-hosted unofficial and missing cases are distinct.
- [Jarník Category II solution availability](catalogs/jarnik-official-solutions.md):
  located links with current HTTP 503 access limitations.
- [IMC solution availability](catalogs/imc-official-solutions.md): archive links
  from 1994–2025; retrieved complete answers for the indexed 2023–2025 problems.

A linked official answer has not thereby received our mathematical proof review.
A successful HTTP HEAD check does not mean the whole paper was downloaded or read.
Failure to locate an answer does not establish that an official answer does not exist.
