# Yau Analysis problem catalog

This first edition indexes **152 numbered written Analysis problems in 26 papers, 2010–2025**: 94 Individual/main problems and 58 Team problems. Titles, subject classifications, prerequisites and difficulty below are editorial judgments; use the original source for every condition. No hints or authored solutions appear here.

[Official Downloads page](https://yau-contest.com/en/lists-jxxg.html) · [Written archive download](https://yau-contest.com/index/reldown?en=1&id=9) · [Machine-readable catalog](yau-analysis.json) · [Exact source manifest](yau-source-manifest.json)

The written ZIP contains official solution PDFs for 2020–2022. Open only the problem member when practicing. Official-solution member names are on the separate [official solution access page](yau-official-solutions.md). Source-issue details and counterexamples are in a separate [editorial source-issues file](yau-source-issues.md), which contains spoilers.

The downloaded oral archive supplies 40 Analysis file members across 2012–2025; this edition records their filenames and hashes only. Oral numbering, exact problem counts, language and embedded solutions remain unverified. Written non-Analysis files are also inventoried without problem indexing. 2026 member names are inventory-only: no 2026 source member was extracted or read.

Difficulty: **entry advanced** = a useful entry point after the stated foundations; **advanced** = substantial undergraduate technique; **very advanced** = substantial specialized theory or a long proof. These are estimates, not official rankings. The detailed JSON provides broad prerequisites, source pages and exact archive member names.
