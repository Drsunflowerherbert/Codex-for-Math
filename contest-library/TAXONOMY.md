# Editorial taxonomy

These labels help choose practice; they are judgments made for this edition,
not official contest difficulty ratings.

| Subject | Interpretation |
| --- | --- |
| analysis | Real/complex/functional analysis, integration, differential equations and analytic inequalities |
| algebra | Linear/abstract algebra, polynomial algebra and number theory |
| geometry | Euclidean/differential geometry and geometric inequalities |
| topology | Topological spaces, continuity/compactness and topological invariants |
| probability | Probability laws, random variables, expectation and stochastic questions |
| combinatorics | Discrete structures, counting, graph theory and finite extremal arguments |

Multiple labels are allowed. A topology prerequisite inside an analysis problem
need not change its official subject. Number theory is grouped under algebra in
this six-subject scheme and named explicitly in the topic label.

Difficulty levels describe preparation rather than expected contest scores:
**entry advanced** uses a core undergraduate theorem with a short argument;
**advanced** needs a significant combination or construction; **very advanced**
may depend on specialized graduate material. Where preparation has not been
assessed, the catalog says **unassessed** instead of inventing a rating.
