# Archived university competition library

First edition, 13 October 2026. This is a bounded archive-practice collection,
with official source links and our own reviewed mathematical notes. It is not
an exhaustive collection or a claim that all available official solutions have
been found.

Start with the [spoiler-free problem index](PROBLEMS.md) and
[analysis practice path](PRACTICE.md). The index contains editorial topics and
prerequisites, with original paper numbering preserved. Problem statements are
read at their official sources; no third-party paper collection is mirrored here.

Solutions are opt-in: [official solution access](OFFICIAL-SOLUTIONS.md),
[our authored solutions](solutions/README.md), and [separate hints](hints/README.md).
Do not open those pages before attempting a problem if you want to avoid spoilers.

The [coverage manifest](COVERAGE.md) states exactly what is indexed and what is
missing. Machine-readable records live in [catalogs/](catalogs/).
[Source and publication policy](SOURCE-POLICY.md) explains provenance, rights,
restricted-round exclusions and the status vocabulary. Mathematical issues in
original papers are recorded separately in [errata](ERRATA.md).

Classification, prerequisites and difficulty are editorial judgments. A reviewed
ordinary proof is not a Lean verification. No Lean formalization or novelty claim
is made for this edition.

Run `python contest-library/scripts/validate.py` from the repository root to
check catalog counts, source fields, spoiler separation and publication scope.
The validator checks metadata integrity; it does not establish mathematical truth.
