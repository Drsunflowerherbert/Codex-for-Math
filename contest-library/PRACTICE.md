# First analysis practice path

This path starts with undergraduate real analysis and gradually introduces
functional analysis. Preparation and order are editorial judgments. Open only
the problem papers and keep your own attempt before consulting optional hints
or solutions elsewhere in the collection.

| Order | Archived problem | Preparation | What to practice |
| --- | --- | --- | --- |
| 1 | [IMC 2024, day 1, Problem 2](https://www.imc-math.org.uk/imc2024/imc2024-day1-questions.pdf) | Logarithms, sequences, limits | Track the exact normalization and justify limit operations |
| 2 | Yau 2019, written individual Analysis, Problem 1 | Convexity, continuous-function integration, intermediate value theorem | Separate the inequality from its equality conditions |
| 3 | Yau 2015, written individual Analysis, Problem 2 | Polynomial approximation, continuous functions, integration | Make dependencies of approximation errors explicit |
| 4 | Yau 2014, written individual Analysis, Problem 1 | Completeness, uniform limits, continuity | Distinguish bounds valid for one argument from bounds uniform over the real line |
| 5 | Yau 2017, written individual Analysis, Problem 2(a,b) | Inner products, Hilbert spaces, weak convergence | State precisely which hypotheses change with dimension |
| 6 | Yau 2023, written Analysis, Problem 4 | Lebesgue integration, L², weak convergence, density of continuous functions | State the test function, tolerance and eventual index in the right order |

The five Yau papers are in the organizer’s [past written-paper archive](https://yau-contest.com/en/lists-jxxg.html).
Their exact archive filenames and original numbering are recorded in the
[Yau catalog](catalogs/yau-analysis.md). Downloading the organizer ZIP exposes filenames
for solution papers too; choose the original question paper by its recorded name.
Problem 2017/2 includes both requested parts. If Hilbert spaces are new, pause
after item 4 and learn the definition of weak convergence first.

For each attempt, define functions and values separately: for example, a function
$f_n$ is different from its value $f_n(t)$. State every domain and every integer
index before using it. A convergence claim should identify what is fixed and
what the eventual index may depend on; a uniform claim needs the same bound for
all points in its stated domain. In an integral argument, justify integrability
before exchanging limits or using an inequality. Treat zero or endpoint cases
before division or strictness claims.

After this path, the [Schweitzer 2024 English paper](https://www.bolyai.hu/files/Schweitzer_2024_Feladatsor_angol.pdf)
offers harder analysis in Problems 2, 3 and 6, spanning measure, differentiability
and the heat equation. Problem 6 needs PDE preparation; it is a later stretch.
