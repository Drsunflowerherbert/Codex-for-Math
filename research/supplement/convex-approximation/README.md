# Analytic convex outer approximation

This folder contains an independent ordinary-proof study of the finite-exponential construction in family 325, Lemma `lem:approx`, source lines 457–511 at revision `fd4aeeb2ee4fc729c18d98444fed42fd0529eeeb`.

The main result extends the planar construction to all finite dimensions \(d\geq1\), proves an explicit Hausdorff bound, handles singletons and lower-dimensional sets, and gives compactly nested choices. It does not validate the paper's headline theorem.

For angular chordal radius \(0<\delta<\sqrt2\), support slack \(\varepsilon>0\), and \(L=\operatorname{diam}K\), the bound is

\[
d_H(\overline\Omega,K)\leq
\frac{\varepsilon+\delta\sqrt{1-\delta^2/4}\,L}{1-\delta^2/2}.
\]

The boundary is a regular real-analytic hypersurface analytically diffeomorphic to \(S^{d-1}\); in dimension two it is a regular analytic Jordan curve, and in dimension one it consists of two endpoints. The construction can be selected so that \(\overline\Omega_{j+1}\subset\Omega_j\).
